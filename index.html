PHP Memory Limit & Resource Config

Aanbevolen instellingen voor WooCommerce shops.

Standaard 128M veroorzaakt 500 Out of Memory errors bij WooCommerce checkout.
Aanbevolen Memory (512M)Optimaal
php.iniCONFIG
memory_limit = 512M max_execution_time = 300 upload_max_filesize = 64M post_max_size = 64M
