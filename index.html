Server Onboarding Stappenplan (SOP)

Standaard stappen voor nieuwe server uitrol.

1. Maak server instantie aan in Cloudways (PHP 8.2+, MySQL 8.0) 2. Koppel DNS NSI records via Cloudflare 3. Voer SSH beveiligingsscript uit: sudo bash /scripts/harden-server.sh --domain example.com 4. Test SSL Certificaat en activeer automatisch back-up schema.
