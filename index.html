TeamworkPM SQL Inzichtpagina Query
04-08-2026 Systeem & Data

Gebruik deze query om snel alle lopende taken van een specifiek project op te halen uit de SQL database van TeamworkPM:

SELECT task_id, task_title, assigned_to, due_date FROM teamwork_tasks WHERE project_id = 4821 AND status = 'OPEN' ORDER BY due_date ASC;
Stappenplan: Nieuwe Hosting Server Onboarding
03-08-2026 Processen & SOP

Standaard werkwijze (SOP) bij het aanmaken van een nieuwe klantomgeving op Ploi / Cloudways:

1. Maak server instantie aan in Cloudways (PHP 8.2+, MySQL 8.0) 2. Koppel DNS NSI records via Cloudflare 3. Voer SSH beveiligingsscript uit: sudo bash /scripts/harden-server.sh --domain example.com 4. Test SSL Certificaat en activeer automatisch back-up schema.
